## Release 0.1.0

`Released: 18 September 2026`

### Theme switcher

- Added a theme switcher to the Visual Studio Code status bar. It appears as a
  sun and moon toggle between the language indicator and the Copilot button.
- Added theme cards to the hover panel for switching manually between light,
  dark, and system themes.
- Added automatic system detection. The System theme card shows the device's
  operating system and, on Linux, its distribution name.
- Added eight icon styles for the switcher, drawn from six icon sets: `Lucide`,
  `Tabler Icons`, `Phosphor`, `Bootstrap Icons`, `Font Awesome`, and
  `Material Symbols`.
- Added a Command Palette picker for choosing the preferred light theme, dark
  theme, and icon style.
- Added translations for 28 display languages, following Visual Studio Code's
  display language: `Arabic`, `Armenian`, `Bulgarian`, `Burmese`, `Catalan`,
  `Chinese (Simplified and Traditional)`, `Czech`, `Dutch`, `French`, `German`,
  `Gujarati`, `Hindi`, `Hungarian`, `Indonesian`, `Italian`, `Japanese`,
  `Korean`, `Lithuanian`, `Marathi`, `Polish`, `Portuguese (Brazil)`,
  `Punjabi`, `Russian`, `Spanish`, `Turkish`, `Ukrainian`, and `Vietnamese`.
- Added support for WSL, SSH, and container-based Visual Studio Code
  environments, with the switcher running locally.
